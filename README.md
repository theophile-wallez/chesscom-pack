# Chess.com pack

Chess.com's default pieces, green board and sounds, described by
`pack.json`.

**Private, for personal use only.** These files are Chess.com's work, not
ours to share: keep this repository private.

## Import

1. Make a [fine-grained token](https://github.com/settings/personal-access-tokens/new)
   for this repository alone, with **Contents: Read-only**.
2. In the extension's settings, under **Packs**, paste the token under
   **Private repository?**, then this repository's link, and press **Import**.
3. Pick the pack in the user menu's Board, Piece set and Sound panels.
